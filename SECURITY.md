# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub: **Security →
Report a vulnerability** on this repository (private vulnerability
reporting). Do not open a public issue.

Include what you found, how to reproduce it and what an attacker could do.
You'll get an acknowledgement within 3 working days and a plan within 10.
We'll credit you in the release notes unless you'd rather not be named.

## Supported versions

| Version | Supported |
|---|---|
| `main` and the latest release | Yes |
| Older releases | No: please upgrade |
